# CIFAR-10 Image Classification (MLP-Mixer)

Проект по классификации изображений из набора данных CIFAR-10. 
В основе лежит архитектура **MLP-Mixer**, которая полностью отказывается от сверточных слоев (CNN) в пользу исключительно полносвязных (Linear) слоев. 

Ключевым ограничением проекта было создание модели размером **менее 1 000 000 параметров** с достижением точности свыше 70%.

## Результаты
* **Архитектура:** Кастомный MLP-Mixer (6 блоков, размер патча 4x4)
* **Количество параметров:** 851,082
* **Оптимизатор:** AdamW + CosineAnnealingLR
* **Точность на тестовой выборке (Test Acc):** 81.57%
* **Функция потерь на тестовой выборке (Test Loss):** 0.6975

## Структура проекта
* `src/dataset.py` - загрузка CIFAR-10 и аугментация данных (Albumentations: RandomCrop, HorizontalFlip, CoarseDropout).
* `src/model.py` - реализация архитектуры MLP-Mixer на базе `torch.nn.Linear`.
* `src/train.py` - цикл обучения с автоматическим логированием метрик в локальную базу данных MLflow.

## Зависимости
Проект использует менеджер пакетов `uv` для быстрого и изолированного управления зависимостями. Основной стек:
* `torch`, `torchvision`
* `albumentations`
* `mlflow` (трекинг экспериментов)

## Запуск обучения
```bash
uv run python src/train.py
```

## Для просмотра графиков обучения запустите сервер MLflow:
```bash
uv run mlflow ui --backend-store-uri sqlite:///mlflow.db
```
